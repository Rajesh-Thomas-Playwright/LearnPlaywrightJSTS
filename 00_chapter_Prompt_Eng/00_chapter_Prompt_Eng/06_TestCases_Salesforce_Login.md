## Notes

- **No case has been executed.** These are test designs only.
- Login URL: `https://login.salesforce.com/?locale=in`. Browsers: Chrome and Firefox, latest stable, Windows 11.
- The requirement number is part of each Test ID (TC-LOGIN-nn covers REQ-LOGIN-nn). Requirement IDs are locally assigned.
- Test data is synthetic. Valid credentials are not stored here. Use the placeholders `<VALID_USERNAME>` and `<VALID_PASSWORD>`, supplied through environment variables.
- Exact error messages are Not provided, so expected results describe observable outcomes only.
- **Blocked by missing account:** TC-LOGIN-01, 02, 05, 07 and 09 need a provisioned account. TC-LOGIN-02 can be run against an unknown username as an interim check, but that does not replace it.
- **Not covered because of the exact-10 limit:** separate boundary-length cases, Chrome-versus-Firefox differences, and the reset flow beyond the reset request page.
- Priorities are not set in this format.
